# ~/.dotfiles

Public repo (github.com/bdashrad/dotfiles), deployed into `$HOME` with GNU stow; each top-level dir
except `_setup/` and `_tools/` is a stow package.

* Never commit secrets, work-specific settings, or 1Password vault and item names.
* To set up Claude Code on a machine, follow "Set up Claude Code on a machine" in
  [claude/README.md](claude/README.md), including its "Notes for Claude".
